# Coursework

In this repo I have recollected some relevant coursework that I've done.

### Shrimp Orchestra Project:

The shrimp orchestra project was done to understand better how to assemble and analyze a simple automata moved by a single input.

I liked the idea of making an orchestra, which allowed me to show a variety of movements, and the shrimps made it funnier. I made the shrimps in blender. 
The mechanism is composed by different cams that define the movement of each shrimp and gears to connect the movement between rows.

### Drill Project

The drill project was done with the objective to learn how to create a tool from scratch based in a real drill.

I made the CAD files based in a real hand drill, took some measures and defined the utility of each component to then redesign the object and manufacture it. I had to make the gears in a CNC machine by hand, some of the axes in a lathe and finally join the metal parts welding. 

Thanks to this project I have the capacity to use multiple manufacture methods and tools to build stuff.
